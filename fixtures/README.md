# Tap-LDK Fixtures

These fixtures are the executable source material for the early native
Taproot Assets implementation. Imported files retain source commit provenance
in `manifest.json`; synthetic files are bounded regtest fixtures used to keep
the first Rust tests concrete until an upstream vector exists.

Do not add private keys, seeds, macaroons, certs, bearer tokens, production
issuer data, or real payment material here.
